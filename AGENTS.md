# AGENTS.md

## Stack

Electron, Vite, TypeScript, SCSS

## Commands

`npm install` `npm run dev` `npm run build` `npm run release:win` `npm run release:mac` `npm run release:lin`

## Brand colors

Light theme only. Defined in `src/static/styles/_variables.scss`. Always use these variables, never hardcode colors.

- Primary: `#5cd8d0` (hover `#acf4e6`), text on primary: `#0e0212`. Fills only, never text on cream.
- Primary text (links, icons, focus): `#0a6b75`
- Accent: `#fad174`
- Secondary: `#8465cf`
- Background: `#f7f0e5` (cream), text: `#3a2f33`
