# Design

Light theme only. Define colors in `src/static/styles/_variables.scss` and use those variables throughout the UI. Do not hardcode colors.

- Primary: `--primary` (`#5cd8d0`), hover: `--primary-hover` (`#acf4e6`). Fills only; never use as text on cream.
- Text on primary: `--on-primary` (`#0e0212`).
- Links, action icons, and focus indicators: `--primary-text` (`#0a6b75`).
- Accent: `--accent` (`#fad174`).
- Secondary: `--secondary` (`#8465cf`).
- Background: `--bg` (`#f7f0e5`), body text: `--text-main` (`#3a2f33`).
